# Portfolio

A modern, responsive portfolio website showcasing front-end development skills, projects, and professional experience.

## Features

- **Responsive Design** - Fully responsive layout that works on all devices
- **Interactive Portfolio** - Filterable project gallery (Coded/Designed)
- **Smooth Animations** - Scroll-triggered animations and transitions
- **Contact Form** - Functional contact form with validation
- **Mobile Navigation** - Hamburger menu for mobile devices
- **Modern UI/UX** - Clean and professional design

## Technologies

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations
- **JavaScript** - Interactive functionality
- **Font Awesome** - Icons
- **Google Fonts** - Typography (Poppins)

## Project Structure

```
PORTFOLIO/
├── index.html      # Main HTML file
├── style.css       # Stylesheet
├── script.js        # JavaScript functionality
├── img/            # Image assets
└── README.md       # Documentation
```

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Ziaullah888/Portfolio.git
```

2. Navigate to the project directory:
```bash
cd portfolio
```

3. Open `index.html` in your web browser

## Usage

Simply open `index.html` in your browser. No build process or server required.

## Sections
